# Contributing

Thanks for contributing to the INTERSHIP WITH CODVEDA project. Please follow these steps:

1. Fork the repository (or collaborate directly if you have permissions).
2. Create a feature branch for your work: `git checkout -b feature/your-task`.
3. Add or update the worklist in `README.md` if you change tasks.
4. Run notebooks and ensure changes are reproducible.
5. Commit with clear messages and open a pull request describing your changes.

If you want me to add the official worklist here, paste it into the `README.md` or provide the file path and I'll update it.
