Task List (Levels and Tasks)

Level 1 (Basic)
- Task 1: Data Cleaning and Preprocessing — Load dataset with pandas, handle missing values, remove duplicates, standardize formats. Tools: Python, pandas.
- Task 2: Exploratory Data Analysis (EDA) — Summary statistics, visualizations, correlations. Tools: Python, pandas, matplotlib, seaborn.
- Task 3: Basic Data Visualization — Bar plots, line charts, scatter plots; export images. Tools: Python, matplotlib, seaborn.

Level 2 (Intermediate)
- Task 1: Regression Analysis — Split data, fit linear regression, evaluate metrics. Tools: Python, scikit-learn, pandas.
- Task 2: Time Series Analysis — Decompose series, smoothing, plotting. Tools: Python, pandas, matplotlib, statsmodels.
- Task 3: Clustering Analysis (KMeans) — Standardize data, apply KMeans, elbow method, visualize clusters. Tools: Python, scikit-learn, matplotlib, seaborn.

Level 3 (Advanced)
- Task 1: Predictive Modeling (Classification) — Preprocess, train classifiers, evaluate, hyperparameter tuning. Tools: Python, scikit-learn, pandas.
- Task 2: Building Dashboards with Power BI/Tableau — Create interactive dashboards and publish. Tools: Power BI or Tableau.
- Task 3: Natural Language Processing (NLP) - Sentiment Analysis — Preprocess text, apply sentiment tools, visualize results. Tools: Python, nltk, TextBlob, pandas.
